# Product Manifest

## Product identity
- Workspace: **Discovering**
- Core entity: **Discovery**
- Product type: Symfony-oriented application resource discovery component

## Mission
Build a component that lets an application expose, index, and retrieve relevant resources through a unified discovery model.

## Primary use cases
- global resource discovery
- scoped discovery by resource type
- filtered discovery
- rebuild and diagnose operations
- demo and management UI
- backend portability between local and scalable adapters

## Growth rule
Grow boldly inside the boundary. Do not stay at a toy demo stage if a richer discovery backbone clearly belongs here.
