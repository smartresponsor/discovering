# Product Manifest

## Product definition

Discovering is an application resource discovery component. It indexes application-facing resources into backend-specific discovery stores and retrieves relevant matches through a unified Symfony-oriented surface.

## MVP direction

MVP should already express:

- a stable discovery query model
- result and hit models
- an indexer contract
- at least one working adapter path
- thin HTTP entrypoints
- CLI rebuild and diagnostics
- demo UI and templates
- local manifests that tell future contributors how to evolve each area
