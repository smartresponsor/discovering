# Generated documentation artifacts

This directory is reserved for generated documentation surfaces.

## Current generated surfaces

- `docs/generated/openapi/` for generated OpenAPI output.
- `docs/generated/doctum/` for generated code-reference output if/when a code reference generator is introduced.

## Maintenance rule

Do not place hand-written narrative documentation directly in this directory. Narrative and operational documentation belongs under `docs/discovery/` or `docs/modules/ROOT/pages/`.
