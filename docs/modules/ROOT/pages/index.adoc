= Discovering

Discovering is a Symfony-oriented application resource discovery component.
This Antora surface is intentionally minimal and exists only so the repository can participate as a content producer in the wider documentation ecosystem.

== Documentation role split

This repository keeps documentation separated by role:

* Antora narrative entry surface lives under `docs/modules/ROOT/pages/`.
* Hand-written operational and narrative Markdown remains under `docs/discovery/`.
* Canonical producer-facing manifests live under `docs/manifests/`.
* GitHub-facing repository materials remain at repository root, such as `README.md`.
* Generated API artifacts belong under `docs/generated/openapi/` and should not be hand-maintained.

No central site assembly, Antora playbook, UI customization, or publishing logic is included here.
This repository is only an Antora content producer.
