== Role

Manifests describe component intent, boundaries and publication posture.
They are durable repository assets, so they belong under `docs/manifests/` instead of repository root.

== Root discipline

Root-level one-off patch manifests and temporary delivery metadata are not considered permanent documentation.
They should be retired through touched-file cleanup waves when found.
