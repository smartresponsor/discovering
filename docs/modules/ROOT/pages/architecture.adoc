== Current architectural shape

Discovering is organized as a Symfony-oriented component with the following major contours:

* discovery runtime and retrieval orchestration
* indexing and staged rebuild support
* source-family providers and repositories
* operator and management surfaces
* shared state, rate limiting, logging, and evidence stores

The repository intentionally keeps `App\` as the only application namespace and does not introduce `/src/Domain/` or ports-and-adapters drift.
