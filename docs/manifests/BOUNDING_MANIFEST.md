# Bounding Manifest

## Product identity

Workspace: Discovering  
Core entity: Discovery

## Product mission

Build Discovering as the application resource discovery workspace for indexing, exposing, and retrieving relevant resources inside the application.

## In scope

- indexing and reindexing application resources
- unified discovery query flows
- per-resource discovery flows
- filtered retrieval
- adapter-backed search execution
- operational commands for rebuild, diagnostics and maintenance
- demonstrable UI for querying discovery flows
- discovery result presentation and support diagnostics

## Out of scope

- building a standalone general-purpose search engine
- replacing Elasticsearch, Meilisearch, OpenSearch or database engines
- becoming a generic analytics/reporting platform
- drifting into unrelated product domains
- turning into a catalog-only product search component by default
